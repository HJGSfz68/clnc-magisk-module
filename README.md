# CLNC Magisk Module

一个可直接安装的 Magisk 模块，用于在 root 环境下启动 CLNC，并提供本地网页控制台。

## 当前发布包

- `clnc_v5_final_20260524_193833.zip`

## 功能

- 开机自启 CLNC
- 本地网页控制台，默认地址 `http://127.0.0.1:666`
- 网页支持 `开启`、`检测`、`关闭`
- 后台幂等启动与低频看门狗
- 连续 UDP 异常时自动自恢复
- 自动自恢复期间临时关闭移动数据，降低流量偷跑风险

## 已做优化

- 统一控制脚本 `control.sh`，收口 `start`、`stop`、`status`
- 修复网页按钮行为
- 修复重复启动和锁冲突问题
- 增强开机与后台保活稳定性
- 调整 `tunMtu` 以改善 UDP 链路表现
- 增加 UDP 连续失败检测与自动重启

## 使用方式

1. 在 Magisk 中安装 `clnc_v5_final_20260524_193833.zip`
2. 重启设备
3. 用浏览器访问 `http://127.0.0.1:666`
4. 通过网页按钮管理模块状态
